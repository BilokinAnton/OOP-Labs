## 🔵 Суть двозв’язного списку:

Двозв'язний список - це структура даних, що складається з елементів які містять посилання як на попередній елемент, так і на наступний.
Це дозволяє обходити список і з початку і з кінця.

```
       ┌────────────┐     ┌───────────┐     ┌───────────┐
null <─┤ prev|A|next├─> <─┤prev|B|next├─> <─┤prev|C|next├─> null
       └────────────┘     └───────────┘     └───────────┘
```

## 🧮 Алгоритми:

- Contains: Лінійний пошук. Послідовний перебір усіх вузлів від початку (head) до кінця (tail).
- Add: Лінійний пошук дублікатів + миттєва вставка в кінець. Новий вузол стає новим tail, зв'язуючись із попереднім.
- Remove: Знайдений вузол видаляється шляхом з'єднання його сусідів (prev і next) між собою.
- RetainAll / removeAll: Ітеративний обхід з видаленням непотрібних вузлів.

\* Операції пошуку виконуються за O(n) а маніпуляції зі зв'язками за O(n)
