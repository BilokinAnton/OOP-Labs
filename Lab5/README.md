## 📝 Завдання:

- Підготувати ігрову кімнату для дітей різних вікових груп.
  Іграшок повинно бути фіксована кількість у межах
  виділеної суми грошей. Повинні зустрічатися іграшки для
  різних вікових груп: маленькі, середні та великі машинки,
  ляльки, м'ячі, кубики. Провести сортування іграшок у
  кімнаті за будь-яким параметром. Знайти іграшку в кімнаті,
  що відповідає заданому діапазону вартості.
