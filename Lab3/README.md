# Лабораторна робота №3

### Тема: Класи в мові програмування Java

> [!NOTE]
> Використовується Java + Maven

## 📝 Завдання:

- Визначити клас автомобіль, який складається як мінімум з 5-и полів.
- Створити клас із виконавчим методом, в якому створити масив з об’єктів класу визначеному варіантом (п. 2).
  Відсортувати масив, за одним з полів за зростанням, а за іншим — за спаданням

<br>

## ✅️ Функціонал програми:

- [x] Сортування масиву об'єктів за полями
- [x] Визначення об'єкта ідентичного заданому

<br>

## 📑 Опис алгоритму:

### Сортування:

- Копіювання: Створюється новий масив-дублікат.

- Сортування за першим полем

- Сортування за другим полем

\**Використовується стандартний Arrays.sort та Comparator.comparingInt для оптимізації порівнянь*

### Пошук ідентичного заданому:

*(Лінійний пошук)*

- Ітерація по масиву
- Порівняння значень цільового об'єкта та i-го за полями та адресою

### Способи ініціалізації:
