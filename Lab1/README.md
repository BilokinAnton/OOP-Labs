## 📑 Опис алгоритму з XOR:

### Маємо дві матриці однакової розмірності:

```math
A = \begin{pmatrix}
a_{11} & a_{12} \\
a_{21} & a_{22}
\end{pmatrix}
B = \begin{pmatrix}
b_{11} & b_{12} \\
b_{21} & b_{22}
\end{pmatrix}
```

### Результатом операції буде матриця ідентичної розмірності:

```math
C = \begin{pmatrix}
c_{11} & c_{12} \\
c_{21} & c_{22}
\end{pmatrix}
```

### Знаходження результату:

```math
c_{ij} = a_{ij} \oplus b_{ij}

C = \begin{pmatrix}
a_{11} \oplus b_{11} & a_{12} \oplus b_{12} \\
a_{21} \oplus b_{21} & a_{22} \oplus b_{22}
\end{pmatrix}
```

### Алгоритм:

1. Ітерація по 2-вимірному масиву A:
2. XOR для n-го елемента
3. Запис результату як n елемент нової матриці

## 🧮 Алгоритм суми найменших елементів кожного рядка:

```
МАТРИЦЯ (A)             MIN РЯДКА          RESULT (SUM)
  +-------------+
  |  5  2  8  3 | ───────► ( min: 2 ) ───┐
  |             |                        │
  |  1  9  4  6 | ───────► ( min: 1 ) ───┼──► Σ (2 + 1 + 7) = 10
  |             |                        │
  |  7 10 12  8 | ───────► ( min: 7 ) ───┘
  +-------------+
         │                      │                │
         ▼                      ▼                ▼
     (Вхідні                (Крок 2:         (Крок 3:
      дані)                  пошук)           фінал)
```

1. Створення змінної `result` для результату та змінної `min`(початкове значення - перший елемент рядка) для
   мінімального значення елементу рядка
2. Ітерація по елементах n-ого рядка та оновлення `min` за умови елемент < `min`
3. Збільшення `result` на `min`
