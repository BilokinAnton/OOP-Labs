## 📑 Опис алгоритму:

### Ітерація словами:

1. Пошук наступного пробілу
2. Визначення діапазону, що включає наступне слово

```
Вхід: "java is cool"
       |  | \ індекс розділювача
       |  end 
       start
       
       слово = range(start, end),  end - індекс пробілу
                                   start - попередній end + 1 
Результат:
+------+  +----+  +------+
| java |  | is |  | cool |
+------+  +----+  +------+
```

### Заміна символів:

1. Визначення кінця слова
2. Ітерація по слову з кінця (*для простої логіки видалення символів*) та видалення входжень цього символу

```
СЛОВО:   TEST
ІНДЕКС:  0  1  2  3

[3] <----+--+--+--* (Беремо символ на позиції 3: 'T' - Це символ для видалення) 
|
[2] <----+-------- (Символ 'S' == 'T'? Ні. Йдемо далі)
|
[1] <----+-------- (Символ 'E' == 'T'? Ні. Йдемо далі)
|
[0] <----+-------- (Символ 'T' == 'T'? ТАК! Видаляємо)
```
