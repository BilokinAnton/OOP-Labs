# Лабораторна робота №4

### Тема: Відношення між класами в мові програмування Java

> [!NOTE]
> Використовується Java + Maven

## 📝 Завдання:

- Модифікувати лабораторну роботу No3 наступним чином: для літер,
  слів, речень, розділових знаків та тексту створити окремі класи. Слово
  повинно складатися з масиву літер, речення з масиву слів та розділових
  знаків, текст з масиву речень. Замінити послідовність табуляцій та
  пробілів одним пробілом.

<br>

## ✅️ Функціонал програми:
- [x] Сортування масиву об'єктів за полями
- [x] Визначення об'єкта ідентичного заданому
- [x] Використання масивів спеціалізованих об'єктів для зберігання текстової інформації


## 📑 Опис алгоритму:

### Створення Речення:
- Очищення рядка від пробілів
- Розбиття на слова
- Пошук символів

### Створення тексту:
- Розбиття речення на частини
- Виділення слів
- Виділення розділових знаків
- Збереження порядку елементів
- Збереження порядку елементів
